# 사주모아 UT 프로토타입

상담 후 추가 이용·충전 진입 경험을 관찰하는 사용자 테스트입니다.

- 참가자: https://wildisign.github.io/sajumoa-ut/
- 진행자 기록: https://wildisign.github.io/sajumoa-ut/admin.html
- 새 참가자: https://wildisign.github.io/sajumoa-ut/?new=1

실제 전화·결제·로그인·외부 API는 사용하지 않습니다. 잔액 0은 수동 새로고침 이후 상태를 전제로 합니다.

기록과 답변은 각 기기·브라우저에 저장됩니다. 자동으로 진행자에게 전송되지 않으므로 참가자는 완료 화면에서 JSON을 내려받아 전달하고, 진행자는 기록 화면에서 가져오기를 사용하세요. 진행자 화면은 로그인된 관리자 서버가 아니며 해당 브라우저의 데이터만 표시합니다.

모달의 이용료 결제 또는 X → 하단 탭으로 도착할 수 있습니다. 첫 행동과 실제 도착 경로, 모달 복귀 횟수를 구분하여 기록합니다. 시간·성공률은 자동 계산하지 않습니다. 전화의 04:08 카운트다운은 시뮬레이션입니다.

조건부 B: 잔액 0 모달·홈에서 진행자가 Alt+Shift+Q로 질문 화면을 열면 추가 과업 안내와 M1 분석 제외를 기록합니다. 터치 조작이 필요하면 ?new=1&moderator=1로 시작하세요.

GitHub Pages 설정은 main 브랜치의 /(root)를 사용합니다. 별도 빌드가 필요하지 않습니다.
